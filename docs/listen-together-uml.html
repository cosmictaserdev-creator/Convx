Listen Together UML

Convx has two group-listening paths that share one player. Convx Sync rooms run on a Cloudflare Worker in listen-together-server/. Jam parties run on BitChord's Go server. This page maps the classes, functions and flows on both sides.

Architecture

How the pieces connect

Each path has a manager that drives the shared PlayerConnection through ListenTogetherPlayerConnectionBridge. Only one path runs at a time: joining a Jam first leaves any Convx room.

Cloudflare room server

One Room Durable Object per room code. It handles one message at a time, so its state is the only version of the room. Guard rate-limits room creation per IP.

Jam · client app/…/jam

Party client

The server owns the party state and numbers every change. It schedules each start 350 ms ahead and re-sends the state every 5 s. The client keeps its player on that state with a 1 s reconcile tick.
